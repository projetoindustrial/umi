# Catálogo UMI

Catálogo de consulta e triagem de ferramentas técnicas abertas, bases de dados e normas de engenharia de processos, materiais e dados industriais, feito para o celular.

**Acesse:** https://projetoindustrial.github.io/umi/

- Mapa por camadas, ficha padronizada por item (descrição, tipo, licença, link da fonte) e cadeias por objeto de trabalho.
- Marcas "usar", "ver depois" e "descartar" ficam no próprio aparelho e podem ser exportadas em JSON.
- Funciona offline depois do primeiro acesso.

**Limites:** é um catálogo de uso pessoal, não uma plataforma. Tipos e "candidata a rodar sozinha" são propostas de classificação, não verificadas nas fontes. A maioria das licenças ainda não foi lida na fonte: confirme a licença antes de usar qualquer item em projeto.
